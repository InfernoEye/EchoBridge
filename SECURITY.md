# Security Policy

## Supported releases

Security fixes are generally targeted at the latest EchoBridge Windows release.

## Reporting a vulnerability

Please **do not open a public issue** for an exploitable security problem. Use GitHub's **Report a vulnerability** option in this repository's **Security** tab if enabled. If the option is unavailable, contact a repository maintainer privately through an existing, verified channel instead of posting exploit details publicly.

Never share API tokens, Windows account credentials, private voice recordings or unredacted personal logs in bug reports.

EchoBridge downloads third-party AI components during onboarding. Their licenses, provenance and upstream security updates are independent of EchoBridge's own MIT license.
